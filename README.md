# Dolmario AI – Grußkarten und Bilder animieren

Zwei verständliche lokale ComfyUI-Anleitungen. Beginne mit einem Bild, dann mit einer Animation. **Die neuen vollständigen Tutorial-Filme werden noch produziert. Die kleinen 46/47-Filme sind nur deutsche Formatproben.**

| Aufgabe / Task | Direktdownload / Download | Anleitung / Guide |
|---|---|---|
| 1. Grußkarten / Greeting cards | [Grußkarten: Downloadpaket](downloads/01-grusskarten-v2.zip) | [Deutsch](01-grusskarten/START-DE.md) · [English](01-grusskarten/START-EN.md) |
| 2. Bild animieren / Animate an image | [Animation: Downloadpaket](downloads/02-animation-v2.zip) | [Deutsch](02-animation/START-DE.md) · [English](02-animation/START-EN.md) |

**Herunterladen:** ZIP-Link öffnen → Download raw file / Download-Symbol. Komplett entpacken, START-DE.md oder START-EN.md öffnen. Die ZIPs enthalten die passenden Workflows, Anleitung, Prompts, Prüfhilfe und bei Animation das öffentliche Beispielbild. Große Modelldateien separat nach Anleitung herunterladen.

**First-time users:** Download the kit, fully extract it and open START-EN.md. Import the `.ui.json` file. Models are separate official downloads; no hidden cloud generation is required.

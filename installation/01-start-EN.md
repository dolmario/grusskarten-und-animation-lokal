# Install or open ComfyUI

A workflow is a ready-made plan; model files supply its AI components. The download kit contains plans and instructions, not large model weights or a hidden cloud service.

If ComfyUI already works, keep that installation and use the local address printed in its start window. The archived Strix Halo tests often used port 8189. Do not start a second server on the same port.

For a new installation: open https://www.comfy.org/download, choose the official package for your OS, install into a separate location, create/open a ComfyUI instance if requested and note its model library. Choose your actual graphics backend. AMD Radeon and Apple Silicon need the separate guides below. Open the node canvas. Then download only the files required for your chosen workflow.

Official Windows guide: https://docs.comfy.org/installation/desktop/windows
Official Mac guide: https://docs.comfy.org/installation/desktop/macos
Requirements: https://docs.comfy.org/installation/system_requirements

The current Desktop route is researched, not newly installed or tested here. Archived outputs used the manual ComfyUI installation at commit fa98a189b4271c76f66210e15f81790b555eb610, frontend 1.53.10. UI labels can change. Model disk size does not guarantee memory sufficiency; LTX video is much heavier than one card.
